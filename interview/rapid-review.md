# Rapid Review

Use this as a final checklist. For practice with model reasoning, use the [Scenario Study Guide](scenario-study-guide.md); for precise terms, use its [shared vocabulary](scenario-study-guide.md#shared-vocabulary).

## Before Drawing

- users and critical flows
- read/write ratio
- scale
- latency/availability
- consistency per operation
- retention
- geography
- non-goals

## Data

- source of truth
- access patterns
- indexes
- partition key
- replication
- hot keys/partitions
- retention and archival

## Reliability

- timeout
- retry safety
- idempotency
- overload
- backpressure
- graceful degradation
- region failure
- RPO/RTO

## Async

- delivery semantics
- ordering
- consumer groups
- duplicate handling
- DLQ
- backlog monitoring

## Cache

- key
- TTL
- invalidation
- stampede
- hot key
- eviction

## Close

- most important trade-off
- rejected alternative
- first bottleneck
- 10× evolution
- metrics that trigger the next change
